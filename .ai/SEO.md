# Search Engine Optimization (SEO) & Content Engineering

**Status:** ACTIVE  
**Last Verified:** 2026-10-19  

## 1. Technical Web Configuration
- **Sitemap:** Automatically generated `sitemap.xml` mapping canonical indexable routes.
- **Robots.txt:** Explicit `robots.txt` disallowing private administrative/authenticated endpoints (`/api/`, `/dashboard/`, `/admin/`).
- **Metadata:** Unique `<title>` (50–60 chars) and `<meta name="description">` (140–160 chars) matching explicit search intent.
- **Structured Data:** Valid JSON-LD schema (`SoftwareApplication`, `Article`, `Organization`) on public pages.
- **Heading Hierarchy:** Strictly one `<h1>` per page with sequential `<h2>` -> `<h3>` nesting.

## 2. Google Helpful Content & E-E-A-T Invariants
- **Experience:** Content must be backed by tangible evidence (real benchmarks, terminal output, concrete code snippets).
- **Expertise:** Deep domain precision without shallow abstractions or generic platitudes.
- **Information Gain:** Must provide new value, novel insights, or proprietary workflow comparisons not found in top 5 SERP competitors.
- **Trustworthiness:** Transparent trade-offs and explicit technical limitations.

## 3. Anti-AI / Anti-ChatGPT Content Guardrails
- **Banned Clichés:** Zero usage of AI filler words (`delve`, `tapestry`, `beacon`, `testament`, `multifaceted`, `plethora`, `game-changer`, `fostering`, `harnessing`).
- **Bottom Line Up Front (BLUF):** Core answer or solution provided in the first 50 words; no conversational throat-clearing openings.
- **Syntactic Burstiness:** Natural variation in sentence length (short 3-5 word punches mixed with detailed compound sentences).
